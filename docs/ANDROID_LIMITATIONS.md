# Android status and limitations

No Android project or enforcement code exists at Stage 1. KidsGuard currently makes no Android monitoring, blocking, screen-time, or tamper-resistance claims.

Later Android work must document which capabilities work on ordinary devices, which require explicit runtime permissions, and which require managed-device enrollment. Website filtering and selected-app restrictions must report their actual synchronization and enforcement state and describe platform limits. HTTPS content interception and hidden Accessibility Service surveillance are out of scope.
